Linear buckling analysis#

Linear buckling loads of two laminated cylinders under axial compression, the cylinders Z18 and Z33 of Castro et al. [Castro2014], Table 4. The geometric stiffness matrix \(\boldsymbol{K}_G\) is computed in two ways:

  • from the membrane resultants of a linear static solution, with update_KG: the prebuckling state then contains the bending boundary layers at the supports and the hoop resultants of the restrained Poisson expansion;

  • from a uniform membrane force given directly, with update_KG_constant_stress, without a static analysis.

The same analyses are checked by the tests tests/test_linear_buckling.py (Z18), tests/test_linear_buckling_Z33_displ.py and tests/test_linear_buckling_Z33_constant_stress.py (Z33).

Theory. \(\boldsymbol{K}_G\) is linear in the prebuckling displacements \(\boldsymbol{u}_0\), so the linear buckling problem, see Analyses,

\[\left( \boldsymbol{K}_{C0} + \lambda \boldsymbol{K}_G(\boldsymbol{u}_0) \right) \boldsymbol{\phi} = \boldsymbol{0}\]

gives the multiplier \(\lambda\) of the load that produced \(\boldsymbol{u}_0\), whatever its size. It is solved for the lowest multipliers with the shift-invert mode 'buckling' of eigsh, four of them, from a fixed starting vector and with the shift at half the load multiplier of an estimate of the buckling load, a published value: the transformed eigenvalues near the lowest multipliers are then well separated. The lowest multiplier \(\lambda_1\) is checked by the residual of its eigenpair and by the number of negative pivots of the \(\boldsymbol{L} \boldsymbol{D} \boldsymbol{L}^\top\) factorization of \(\boldsymbol{K}_{C0} + s \boldsymbol{K}_G\) for \(s = (1 - 10^{-6}) \lambda_1\), which by Sylvester’s law of inertia is the number of multipliers between 0 and \(s\): zero when no lower one is missing. When the load is a prescribed shortening of the end \(x = L\), the static solution is that of the unknown degrees of freedom with the known values \(\bar{\boldsymbol{u}}_k\),

\[\boldsymbol{K}_{uu} \boldsymbol{u}_u = -\boldsymbol{K}_{uk} \bar{\boldsymbol{u}}_k, \qquad \boldsymbol{F}_k = \boldsymbol{K}_{uk}^\top \boldsymbol{u}_u + \boldsymbol{K}_{kk} \bar{\boldsymbol{u}}_k\]

and the critical load is \(\lambda\) times the sum of the axial reactions \(\boldsymbol{F}_k\) at \(x = L\).

def table(rows, fmt='{:.5g}'):
    """Markdown table of a list of dicts with the same keys"""
    keys = list(rows[0])
    cell = lambda v: fmt.format(v) if isinstance(v, float) else str(v)
    lines = ['| ' + ' | '.join(keys) + ' |', '|' + '---|'*len(keys)]
    lines += ['| ' + ' | '.join(cell(r[k]) for k in keys) + ' |' for r in rows]
    return Markdown('\n'.join(lines))

Cylinders and material#

Both cylinders have \(R = 250\) mm, \(L = 510\) mm and ten plies of 0.125 mm, the stacking sequences of [Castro2014], Table 4, listed from the inner to the outer surface. The ply material is Geier1997 of [Castro2014], Table 3, the material of the test cylinders of Geier and Singh [GeierSingh1997] and of Z33 in [Geier2002]. The element uses only the laminate stiffnesses \(\boldsymbol{A}\), \(\boldsymbol{B}\), \(\boldsymbol{D}\) of the classical laminated plate theory; the two transverse shear moduli that laminated_plate takes are not used and are given the value of \(G_{12}\).

Mesh, elements and matrices#

The model is built by one function, used for both cylinders: the structured mesh closed around the circumference (see Assembling a model), one BFSCCylinder per element, and the stiffness matrix \(\boldsymbol{K}_{C0}\). It returns what the analyses below need.

[3]:

nint = 4
points, weights = get_points_weights(nint=nint)

def build_model(prop, ny):
    nx = int(ny*L/b)
    nids = 1 + np.arange(nx*(ny+1))
    nids_mesh = nids.reshape(nx, ny+1)
    nids_mesh[:, -1] = nids_mesh[:, 0]  # closes the cylinder
    nids = np.unique(nids_mesh)
    nid_pos = dict(zip(nids, np.arange(len(nids))))
    xmesh, ymesh = np.meshgrid(np.linspace(0, L, nx),
                               np.linspace(0, b, ny+1)[:-1], indexing='ij')
    n1s = nids_mesh[:-1, :-1].flatten()
    n2s = nids_mesh[1:, :-1].flatten()
    n3s = nids_mesh[1:, 1:].flatten()
    n4s = nids_mesh[:-1, 1:].flatten()
    N = DOF*nx*ny
    elements = []
    for k, (n1, n2, n3, n4) in enumerate(zip(n1s, n2s, n3s, n4s)):
        shell = BFSCCylinder(nint)
        shell.c1 = DOF*nid_pos[n1]
        shell.c2 = DOF*nid_pos[n2]
        shell.c3 = DOF*nid_pos[n3]
        shell.c4 = DOF*nid_pos[n4]
        shell.R = R
        shell.lex = L/(nx - 1)
        shell.ley = b/ny
        assign_constant_ABD(shell, prop)
        shell.init_k_KC0 = k*KC0_SPARSE_SIZE
        shell.init_k_KG = k*KG_SPARSE_SIZE
        elements.append(shell)
    ne = len(elements)
    Kr = np.zeros(KC0_SPARSE_SIZE*ne, dtype=INT)
    Kc = np.zeros(KC0_SPARSE_SIZE*ne, dtype=INT)
    Kv = np.zeros(KC0_SPARSE_SIZE*ne, dtype=DOUBLE)
    for shell in elements:
        update_KC0(shell, points, weights, Kr, Kc, Kv)
    KC0 = coo_matrix((Kv, (Kr, Kc)), shape=(N, N)).tocsc()
    return dict(nx=nx, ny=ny, N=N, x=xmesh.flatten(), y=ymesh.flatten(),
                xmesh=xmesh, ymesh=ymesh, elements=elements, KC0=KC0)

def new_KG(model):
    size = KG_SPARSE_SIZE*len(model['elements'])
    return (np.zeros(size, dtype=INT), np.zeros(size, dtype=INT),
            np.zeros(size, dtype=DOUBLE))

def constrain_ends(model, dofs):
    bk = np.zeros(model['N'], dtype=bool)
    ends = isclose(model['x'], 0) | isclose(model['x'], L)
    for dof in dofs:
        bk[dof::DOF] = ends
    return bk

The eigenvalue solution, and the two analyses as functions of the model, of the constrained degrees of freedom at both ends and of the estimate P_est of the buckling load, which sets the shift:

[4]:

def negative_pivots(A):
    """number of negative eigenvalues of the symmetric matrix A, from the
    LDL^T factorization with a symmetric permutation"""
    lu = splu(A.tocsc(), permc_spec='MMD_AT_PLUS_A', diag_pivot_thresh=0.,
              options=dict(SymmetricMode=True))
    if not np.array_equal(lu.perm_r, lu.perm_c):
        raise RuntimeError('row interchange, the count is not the inertia')
    return int(np.count_nonzero(lu.U.diagonal() < 0))

def lowest_load_multiplier(Kuu, KGuu, estimate, k=4):
    """lowest load multiplier and its mode, with the residual of the pair and
    the number of load multipliers below it"""
    eigvals, eigvecs = eigsh(A=Kuu, k=k, which='LM', M=KGuu,
                             sigma=-0.5*estimate, mode='buckling',
                             v0=np.ones(Kuu.shape[0]))
    load_mult = -eigvals
    i = np.argmin(load_mult)
    lm, phi = load_mult[i], eigvecs[:, i]
    residual = norm(Kuu @ phi + lm*(KGuu @ phi))/norm(Kuu @ phi)
    below = negative_pivots(Kuu + (1 - 1e-6)*lm*KGuu)
    return lm, phi, residual, below

def buckling_shortening(model, dofs, P_est, shortening=-0.001):
    """K_G of the linear static solution of a prescribed end shortening"""
    N, x, KC0 = model['N'], model['x'], model['KC0']
    bk = constrain_ends(model, dofs)
    bu = ~bk
    top = isclose(x, L)
    u = np.zeros(N)
    u[0::DOF][top] = shortening
    uk = u[bk]
    Kuk = KC0[bu][:, bk]
    u[bu] = spsolve(KC0[bu][:, bu], -Kuk @ uk)
    KGr, KGc, KGv = new_KG(model)
    for shell in model['elements']:
        update_KG(u, shell, points, weights, KGr, KGc, KGv)
    KG = coo_matrix((KGv, (KGr, KGc)), shape=(N, N)).tocsc()
    # reactions at the known degrees of freedom
    f = np.zeros(N)
    f[bk] = Kuk.T @ u[bu] + KC0[bk][:, bk] @ uk
    F = f[0::DOF][top].sum()
    lm, phi, residual, below = lowest_load_multiplier(
        KC0[bu][:, bu], KG[bu][:, bu], estimate=P_est/abs(F))
    mode = np.zeros(N)
    mode[bu] = phi
    return lm*F, mode, residual, below

def buckling_constant_stress(model, dofs, P_est, Nxx=-1.):
    """K_G of a uniform axial membrane force Nxx"""
    N, KC0 = model['N'], model['KC0']
    bk = constrain_ends(model, dofs)
    bu = ~bk
    KGr, KGc, KGv = new_KG(model)
    for shell in model['elements']:
        update_KG_constant_stress(shell, points, weights, KGr, KGc, KGv,
                                  Nxx, 0., 0.)
    KG = coo_matrix((KGv, (KGr, KGc)), shape=(N, N)).tocsc()
    lm, phi, residual, below = lowest_load_multiplier(
        KC0[bu][:, bu], KG[bu][:, bu], estimate=P_est/(abs(Nxx)*b))
    mode = np.zeros(N)
    mode[bu] = phi
    return lm*Nxx*b, mode, residual, below

def plot_mode(model, mode, title):
    w = mode[6::DOF].reshape(model['nx'], model['ny'])
    fig, ax = plt.subplots(figsize=(7, 3.0))
    c = ax.contourf(model['ymesh']*1e3, model['xmesh']*1e3, w/np.abs(w).max(),
                    levels=50, cmap='coolwarm')
    fig.colorbar(c, ax=ax, label='$w / |w|_{max}$')
    ax.set_xlabel('$y$ (mm), around the circumference')
    ax.set_ylabel('$x$ (mm)')
    ax.set_aspect('equal')
    ax.set_title(title)
    plt.show()

Cylinder Z18, simply supported#

The ends have \(u = v = w = 0\) at the nodes and \(w_{,x}\) free, the conditions SS1 of [Castro2014], Table 1; between two nodes of an end \(w\) is the cubic of the nodal \(w\) and \(w_{,y}\), so \(w = 0\) holds exactly only at the nodes, a difference that vanishes with mesh refinement, see Assembling a model.

The end \(x = L\) is shortened by 1 mm; 60 nodes around the circumference. The estimate for the shift is 226.44 kN, [Castro2014], Table 6 (SS2).

[5]:

z18 = build_model(props['Z18'], ny=60)
P_z18, mode_z18, res, below = buckling_shortening(z18, dofs=(0, 3, 6),
                                                  P_est=226.44e3)
print(f'Z18: P_cr = {abs(P_z18)/1e3:.2f} kN, residual {res:.1e}, '
      f'load multipliers below: {below}')
plot_mode(z18, mode_z18, f'Z18, $P_{{cr}}$ = {abs(P_z18)/1e3:.1f} kN')

Z18: P_cr = 228.47 kN, residual 3.2e-13, load multipliers below: 0

Cylinder Z33, clamped#

The ends are clamped, \(u = v = w = w_{,x} = 0\), the conditions CC1 of [Castro2014], Table 1, with 50 nodes around the circumference. Unlike the simple support of Z18, the derivatives along the edge, \(u_{,y}\), \(v_{,y}\), \(w_{,y}\) and \(w_{,xy}\), are constrained too, so that the conditions hold along the whole edge: at a clamped end the deviation between the nodes is larger, see Assembling a model. The static prebuckling state of a prescribed shortening and the uniform membrane force are compared. The estimate for the shift is 192 kN, [Geier2002], Table 1.

[6]:

z33 = build_model(props['Z33'], ny=50)
clamped = (0, 2, 3, 5, 6, 7, 8, 9)  # u, u_y, v, v_y, w, w_x, w_y, w_xy
P_z33_s, mode_z33, res_s, below_s = buckling_shortening(
    z33, dofs=clamped, P_est=192e3)
P_z33_c, _, res_c, below_c = buckling_constant_stress(
    z33, dofs=clamped, P_est=192e3)
print(f'Z33, static prebuckling state: P_cr = {abs(P_z33_s)/1e3:.2f} kN, '
      f'residual {res_s:.1e}, load multipliers below: {below_s}')
print(f'Z33, uniform membrane force:   P_cr = {abs(P_z33_c)/1e3:.2f} kN, '
      f'residual {res_c:.1e}, load multipliers below: {below_c}')
plot_mode(z33, mode_z33, f'Z33, $P_{{cr}}$ = {abs(P_z33_s)/1e3:.1f} kN')

Comparison#

  • Z33: the buckling load of Geier et al. [Geier2002], Table 1, 192 kN, the result BACCUS-C4 (built-in edges, deep shell theory, homogeneous membrane prebuckling state); the tests of the same paper gave 173 kN and 184 kN.

  • Z18: [Castro2014], Table 6, gives with the classical laminated plate theory 226.44 kN for the conditions SS2 (\(v = w = 0\), \(u\) free) and 228.22 kN for CC2 (\(v = w = w_{,x} = 0\)), and the test result 212.6 kN of Geier et al.; the conditions here, with \(u\) also constrained, are between the two.

The table also gives the regression values stored in the tests, results of the same models.
