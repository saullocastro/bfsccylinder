Nonlinear static analysis with structsolve#

structsolve.Analysis, of structsolve, solves nonlinear static problems from four callables written by the user: calc_fext, calc_fint, calc_kC and calc_kG. This example shows the callables of a model of bfsccylinder elements, see the section Solving with structsolve of Analyses, first for dead loads and then for a follower pressure, whose load stiffness matrix is unsymmetric. The callables are those of the tests tests/test_nonlinear_axial_compression.py and tests/test_follower_pressure_structsolve.py, imported from there.

def table(rows, fmt='{:.5g}'):
    """Markdown table of a list of dicts with the same keys"""
    keys = list(rows[0])
    cell = lambda v: fmt.format(v) if isinstance(v, float) else str(v)
    lines = ['| ' + ' | '.join(keys) + ' |', '|' + '---|'*len(keys)]
    lines += ['| ' + ' | '.join(cell(r[k]) for k in keys) + ' |' for r in rows]
    return Markdown('\n'.join(lines))

Callables for dead loads#

The callables work on the unknown degrees of freedom bu, the partition of the free degrees of freedom of structsolve: the solution vector of the solvers is \(\boldsymbol{c} = \boldsymbol{u}_u\), the prescribed degrees of freedom being zero, and expand gives the displacements of the whole model. calc_fint assembles the internal forces of update_fint; calc_kC gives \(\boldsymbol{K}_{C0}\), or, with NLgeom=True, \(\boldsymbol{K}_{C0} + \boldsymbol{K}_{CNL} + \boldsymbol{K}_{GNL}\) of update_KCNL; calc_kG gives \(\boldsymbol{K}_G\) of update_KG. Their sum is the tangent stiffness matrix \(\boldsymbol{K}_T\), the exact Jacobian of the residual \(\boldsymbol{F}_{int}(\boldsymbol{u}) - \lambda \boldsymbol{F}_{ext}\), and the value arrays of the sparse matrices are zeroed in each call, since the update functions add to them:

[2]:

print(inspect.getsource(Callables))

class Callables(object):
    """The callables of structsolve.Analysis for the ``elements`` of a model
    under the external forces ``fext``.

    They loop over the elements with the update functions and assemble, and
    work on the unknown degrees of freedom ``bu`` only, the partition of the
    free dofs of structsolve: the solution vector of the solvers is ``c =
    u[bu]``, and the force vectors and matrices are restricted to ``bu``.
    The prescribed degrees of freedom are zero.
    """
    def __init__(self, elements, points, weights, KC0, bu, fext):
        self.elements = elements
        self.points = points
        self.weights = weights
        self.N = KC0.shape[0]
        self.KC0 = KC0
        self.KC0uu = KC0[bu, :][:, bu]
        self.bu = bu
        self.fext = fext
        num_elements = len(elements)
        self.KCNLr = np.zeros(KCNL_SPARSE_SIZE*num_elements, dtype=INT)
        self.KCNLc = np.zeros(KCNL_SPARSE_SIZE*num_elements, dtype=INT)
        self.KCNLv = np.zeros(KCNL_SPARSE_SIZE*num_elements, dtype=DOUBLE)
        self.KGr = np.zeros(KG_SPARSE_SIZE*num_elements, dtype=INT)
        self.KGc = np.zeros(KG_SPARSE_SIZE*num_elements, dtype=INT)
        self.KGv = np.zeros(KG_SPARSE_SIZE*num_elements, dtype=DOUBLE)

    def expand(self, c):
        """The displacements of the model from those of the unknown dofs."""
        u = np.zeros(self.N, dtype=DOUBLE)
        u[self.bu] = c
        return u

    def calc_fext(self, inc=1., silent=False):
        return inc*self.fext[self.bu]

    def calc_fint(self, c, silent=False):
        fint = np.zeros(self.N, dtype=DOUBLE)
        u = self.expand(c)
        for shell in self.elements:
            update_fint(u, shell, self.points, self.weights, fint)
        return fint[self.bu]

    def calc_kC(self, c=None, NLgeom=False, silent=False):
        if not NLgeom:
            return self.KC0uu
        # the generated code accumulates with "+=" over the integration
        # points, so the value arrays must be zeroed on every call. The row
        # and column arrays are rewritten identically each time, and could
        # be filled once for a fixed mesh
        self.KCNLv *= 0
        u = self.expand(c)
        for shell in self.elements:
            update_KCNL(u, shell, self.points, self.weights, self.KCNLr,
                        self.KCNLc, self.KCNLv)
        KCNL = coo_matrix((self.KCNLv, (self.KCNLr, self.KCNLc)),
                          shape=(self.N, self.N)).tocsc()
        # KCNL also carries the geometric term of the nonlinear membrane
        # stress, so that KG stays homogeneous of degree one in u and keeps
        # its linear buckling meaning. KC0 + KCNL + KG is d(fint)/du
        return (self.KC0 + KCNL)[self.bu, :][:, self.bu]

    def calc_kG(self, c=None, NLgeom=False, silent=False):
        self.KGv *= 0
        u = self.expand(c)
        for shell in self.elements:
            update_KG(u, shell, self.points, self.weights, self.KGr,
                      self.KGc, self.KGv)
        KG = coo_matrix((self.KGv, (self.KGr, self.KGc)),
                        shape=(self.N, self.N)).tocsc()
        return KG[self.bu, :][:, self.bu]

Callables for a follower pressure#

A pressure normal to the deformed shell depends on the displacements. With the follower pressure \(\lambda p_0\) the residual and its Jacobian are, see Follower pressure,

\[\boldsymbol{R}(\boldsymbol{u}) = \boldsymbol{F}_{int}(\boldsymbol{u}) - \lambda \boldsymbol{F}_p(\boldsymbol{u}), \qquad \boldsymbol{K}_T = \boldsymbol{K}_{C0} + \boldsymbol{K}_{CNL} + \boldsymbol{K}_{GNL} + \boldsymbol{K}_G + \boldsymbol{K}_F\]

The callables receive the load factor inc: calc_fext gives the dead part \(\lambda \boldsymbol{F}_p(\boldsymbol{0})\), calc_fint subtracts the part that depends on the displacements, \(\lambda (\boldsymbol{F}_p(\boldsymbol{u}) - \boldsymbol{F}_p(\boldsymbol{0}))\), of update_fext_follower with reference=0, and calc_kC adds the load stiffness matrix \(\boldsymbol{K}_F\) of \(\lambda p_0\) of update_KCfollower. They also record the iterations, to follow the convergence:

[3]:

print(inspect.getsource(FollowerCallables))

class FollowerCallables(object):
    r"""The callables of structsolve.Analysis for the ``elements`` of the
    module ``mod`` under the follower pressures ``pressures``, one array of
    shape ``(nint, nint)`` per element, times the load factor

    They loop over the elements with the update functions and assemble, and
    work on the unknown degrees of freedom ``bu`` only, the partition of the
    free dofs of structsolve: the solution vector of the solvers is ``c =
    u[bu]``, and the force vectors and matrices are restricted to ``bu``.
    ``quadratic`` is the truncation of the area vector. ``calc_fint`` also
    keeps the load factor and the internal forces of each iteration, for the
    residual history.
    """
    def __init__(self, mod, elements, points, weights, N, bu, pressures,
                 quadratic=0):
        self.mod = mod
        self.elements = elements
        self.points = points
        self.weights = weights
        self.N = N
        self.bu = bu
        self.pressures = pressures
        self.quadratic = quadratic
        self.iterations = []
        self.KC0 = assemble(mod, elements, mod.update_KC0, 'KC0', N,
                            (points, weights))
        num_elements = len(elements)
        for i, shell in enumerate(elements):
            shell.init_k_KCNL = i*mod.KCNL_SPARSE_SIZE
            shell.init_k_KG = i*mod.KG_SPARSE_SIZE
            shell.init_k_KCfollower = i*mod.KCfollower_SPARSE_SIZE
        size = mod.KCNL_SPARSE_SIZE*num_elements
        self.KCNLr = np.zeros(size, dtype=mod.INT)
        self.KCNLc = np.zeros(size, dtype=mod.INT)
        self.KCNLv = np.zeros(size, dtype=mod.DOUBLE)
        size = mod.KG_SPARSE_SIZE*num_elements
        self.KGr = np.zeros(size, dtype=mod.INT)
        self.KGc = np.zeros(size, dtype=mod.INT)
        self.KGv = np.zeros(size, dtype=mod.DOUBLE)
        size = mod.KCfollower_SPARSE_SIZE*num_elements
        self.KCfr = np.zeros(size, dtype=mod.INT)
        self.KCfc = np.zeros(size, dtype=mod.INT)
        self.KCfv = np.zeros(size, dtype=mod.DOUBLE)
        # the dead part of the pressure, the force vector at u = 0
        self.fp0 = np.zeros(N, dtype=mod.DOUBLE)
        for shell, p in zip(elements, pressures):
            mod.update_fext_follower(np.zeros(N), shell, points, weights, p,
                                     self.fp0, quadratic)

    def expand(self, c):
        """The displacements of the model from those of the unknown dofs."""
        u = np.zeros(self.N, dtype=self.mod.DOUBLE)
        u[self.bu] = c
        return u

    def calc_fext(self, inc=1., silent=False):
        return inc*self.fp0[self.bu]

    def calc_fint(self, c, inc=1., silent=False):
        mod = self.mod
        u = self.expand(c)
        fint = np.zeros(self.N, dtype=mod.DOUBLE)
        for shell, p in zip(self.elements, self.pressures):
            mod.update_fint(u, shell, self.points, self.weights, fint)
            # minus the part of the follower pressure that depends on u
            mod.update_fext_follower(u, shell, self.points, self.weights,
                                     -inc*p, fint, self.quadratic, 0)
        self.iterations.append((inc, fint[self.bu]))
        return fint[self.bu]

    def calc_kC(self, c=None, NLgeom=False, inc=1., silent=False):
        bu = self.bu
        if not NLgeom:
            return self.KC0[bu, :][:, bu]
        mod = self.mod
        u = self.expand(c)
        self.KCNLv *= 0
        self.KCfv *= 0
        for shell, p in zip(self.elements, self.pressures):
            mod.update_KCNL(u, shell, self.points, self.weights, self.KCNLr,
                            self.KCNLc, self.KCNLv)
            # the load stiffness matrix of the pressure inc*p
            mod.update_KCfollower(u, shell, self.points, self.weights,
                                  inc*p, self.KCfr, self.KCfc, self.KCfv,
                                  self.quadratic)
        KCNL = coo_matrix((self.KCNLv, (self.KCNLr, self.KCNLc)),
                          shape=(self.N, self.N))
        KCf = coo_matrix((self.KCfv, (self.KCfr, self.KCfc)),
                         shape=(self.N, self.N))
        return (self.KC0 + KCNL + KCf).tocsc()[bu, :][:, bu]

    def calc_kG(self, c=None, NLgeom=False, silent=False):
        mod = self.mod
        u = self.expand(c)
        self.KGv *= 0
        for shell in self.elements:
            mod.update_KG(u, shell, self.points, self.weights, self.KGr,
                          self.KGc, self.KGv)
        KG = coo_matrix((self.KGv, (self.KGr, self.KGc)),
                        shape=(self.N, self.N))
        return KG.tocsc()[self.bu, :][:, self.bu]

Clamped-free cylinder#

\(R = 1\) m, \(L = 1\) m and \(h = 10\) mm, isotropic, with the \(E\) and \(\nu\) of tests/test_follower_pressure_validation.py, whose cylinder_model builds the mesh of 7 by 24 nodes and the elements of either kinematics. All ten degrees of freedom are constrained at the nodes of \(x = 0\); the end \(x = L\) is free. The external pressure \(p = -2 (1 + \cos(3 y/R)/2)\) bar varies around the circumference and is given at the integration points of each element. The load stiffness matrix is symmetric only if \(p\) is uniform and, along the contour of the loaded region, \(w = 0\) or the in-plane displacement normal to the contour vanishes [Hibbitt1979], [SchweizerhofRamm1984]: here both conditions fail.

[4]:

R, L, h = 1., 1., 0.01  # m
prop = isotropic_plate(thickness=h, E=E, nu=NU)
print(f'E = {E/1e9} GPa, nu = {NU}')

def pressures_of(elements, y, points):
    """p at the integration points of each element, shape (nint, nint)"""
    nint = len(points)
    out = []
    for shell in elements:
        yj = y[shell.n1] + shell.ley*(points + 1)/2
        p = -2.e5*(1 + 0.5*np.cos(3*yj/R))  # Pa
        out.append(np.ascontiguousarray(np.ones((nint, 1))*p[None, :]))
    return out

E = 70.0 GPa, nu = 0.3

The analysis, for both kinematics, in two equal increments of the load factor, 0.5 and 1. After it, the equilibrium with the whole follower pressure is checked with \(\boldsymbol{F}_p\) at the final displacements, the asymmetry of \(\boldsymbol{K}_F\) is measured, and the convergence history of each increment is computed with Crisfield’s criterion \(\zeta\) [Crisfield1981], the criterion of structsolve.

[5]:

results = {}
for kinematics in sorted(KINEMATICS):
    mod, elements, points, weights, x, y, N = cylinder_model(
        kinematics, L, R, prop, nx=7, ny=24)
    DOF = mod.DOF
    bk = np.zeros(N, dtype=bool)
    for i in range(DOF):
        bk[i::DOF] |= isclose(x, 0)
    bu = ~bk
    pressures = pressures_of(elements, y, points)
    callables = FollowerCallables(mod, elements, points, weights, N, bu,
                                  pressures)
    an = Analysis(calc_fext=callables.calc_fext, calc_fint=callables.calc_fint,
                  calc_kC=callables.calc_kC, calc_kG=callables.calc_kG)
    an.initialInc = 0.5
    an.maxInc = 0.5
    increments, cs = an.static(NLgeom=True)
    u = callables.expand(cs[-1])

    fint = np.zeros(N)
    fp = np.zeros(N)
    for shell, p in zip(elements, pressures):
        mod.update_fint(u, shell, points, weights, fint)
        mod.update_fext_follower(u, shell, points, weights, p, fp)
    residual = np.linalg.norm((fint - fp)[bu])/np.linalg.norm(fp[bu])
    follower = (np.linalg.norm((fp - callables.fp0)[bu])
                /np.linalg.norm(callables.fp0[bu]))

    KCf = (callables.calc_kC(cs[-1], NLgeom=True, inc=1.)
           - callables.calc_kC(cs[-1], NLgeom=True, inc=0.)).toarray()
    asym = np.abs(KCf - KCf.T).max()/np.abs(KCf).max()

    wts = crisfield_weights(callables.KC0[bu, :][:, bu])
    f = callables.fp0[bu]
    zeta = {lbd: [crisfield_zeta(inc*f - fi, inc*f, fi, wts)
                  for inc, fi in callables.iterations if inc == lbd]
            for lbd in increments}
    results[kinematics] = dict(increments=increments, u=u, x=x, y=y, N=N,
                               DOF=DOF, wmax=np.abs(u[6::DOF]).max()/h,
                               residual=residual, follower=follower,
                               asym=asym, zeta=zeta)

Results#

Both increments converged without a cut. The table gives, for each kinematics, the largest \(|w|/h\), the relative residual with the whole follower pressure, the relative size of the follower part of the load, \(\| \boldsymbol{F}_p(\boldsymbol{u}) - \boldsymbol{F}_p(\boldsymbol{0}) \| / \| \boldsymbol{F}_p(\boldsymbol{0}) \|\), and the asymmetry \(\max |\boldsymbol{K}_F - \boldsymbol{K}_F^\top| / \max |\boldsymbol{K}_F|\). No published value exists for this case; the Sanders-type result is the reference of the Donnell-type one.
