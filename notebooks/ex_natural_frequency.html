Natural frequencies#

The lowest natural frequencies and modes of a thin isotropic cylinder supported at both ends. The example assembles the stiffness matrix of update_KC0 and the consistent mass matrix of update_M, and solves the generalized eigenvalue problem with a verified solver. The same model is checked by the test tests/test_natural_frequency.py.

Theory. The natural frequencies \(\omega_n\) and the modes \(\boldsymbol{\phi}\) solve, see Analyses,

\[\left( \boldsymbol{K}_{C0} - \omega_n^2 \boldsymbol{M} \right) \boldsymbol{\phi} = \boldsymbol{0}\]

with \(\boldsymbol{K}_{C0}\) positive definite once the rigid-body motions are constrained and \(\boldsymbol{M}\) the consistent mass matrix, which includes the rotary inertia of the rotations of the normal, see Element matrices and internal forces. The frequencies of a closed cylinder come in pairs of equal values, the modes \(\cos(n\theta)\) and \(\sin(n\theta)\) of the same number \(n\) of circumferential waves, and the lowest pairs lie close to each other [Leissa1973]. An iterative eigensolver can then miss or swap eigenvalues, which is why the function lowest_frequencies of tests/natural_frequency_solver.py is used: it computes the eigenvalues with ARPACK in shift-invert mode, with the shift \(-1\) below the lowest eigenvalue and a fixed starting vector, checks the residual of each eigenpair, and, by Sylvester’s law of inertia, counts the negative pivots of an \(\boldsymbol{L}\boldsymbol{D}\boldsymbol{L}^\top\) factorization of \(\boldsymbol{K} - s \boldsymbol{M}\), with \(s\) slightly above the highest eigenvalue returned, to verify that none is missing.

def table(rows, fmt='{:.5g}'):
    """Markdown table of a list of dicts with the same keys"""
    keys = list(rows[0])
    cell = lambda v: fmt.format(v) if isinstance(v, float) else str(v)
    lines = ['| ' + ' | '.join(keys) + ' |', '|' + '---|'*len(keys)]
    lines += ['| ' + ' | '.join(cell(r[k]) for k in keys) + ' |' for r in rows]
    return Markdown('\n'.join(lines))

Geometry, material and mesh#

\(R = 0.4\) m, \(L = 0.8\) m, \(h = 1\) mm, aluminium, \(E = 70\) GPa, \(\nu = 0.33\) and \(\rho = 2700\) kg/m\(^3\); 21 nodes along the axis and 56 around the circumference.

[2]:

L = 0.8  # m
R = 0.4  # m
b = 2*pi*R  # m
E = 70e9  # Pa
nu = 0.33
h = 0.001  # m
rho = 2.7e3  # kg/m3
prop = isotropic_plate(thickness=h, E=E, nu=nu)

nx = 21
ny = 56

# node numbers on a grid of nx by ny + 1, the last column closing the cylinder
nids = 1 + np.arange(nx*(ny+1))
nids_mesh = nids.reshape(nx, ny+1)
nids_mesh[:, -1] = nids_mesh[:, 0]
nids = np.unique(nids_mesh)
nid_pos = dict(zip(nids, np.arange(len(nids))))

# coordinates of the nodes on the developed mid-surface
xlin = np.linspace(0, L, nx)
ylin = np.linspace(0, b, ny+1)[:-1]
xmesh, ymesh = np.meshgrid(xlin, ylin, indexing='ij')
x = xmesh.flatten()
y = ymesh.flatten()

# the four nodes of each element, counterclockwise from (x_i, y_j)
n1s = nids_mesh[:-1, :-1].flatten()
n2s = nids_mesh[1:, :-1].flatten()
n3s = nids_mesh[1:, 1:].flatten()
n4s = nids_mesh[:-1, 1:].flatten()
num_elements = len(n1s)
N = DOF*nx*ny
print('nodes:', nx*ny, ' elements:', num_elements, ' degrees of freedom:', N)

Stiffness and mass matrices#

The mass matrix needs the thickness h and the density rho of each element; update_M writes its entries at the positions init_k_M.

[3]:

nint = 4
points, weights = get_points_weights(nint=nint)

elements = []
for k, (n1, n2, n3, n4) in enumerate(zip(n1s, n2s, n3s, n4s)):
    shell = BFSCCylinder(nint)
    shell.n1, shell.n2, shell.n3, shell.n4 = n1, n2, n3, n4
    shell.c1 = DOF*nid_pos[n1]
    shell.c2 = DOF*nid_pos[n2]
    shell.c3 = DOF*nid_pos[n3]
    shell.c4 = DOF*nid_pos[n4]
    shell.R = R
    shell.lex = L/(nx - 1)
    shell.ley = b/ny
    shell.h = h
    shell.rho = rho
    assign_constant_ABD(shell, prop)
    shell.init_k_KC0 = k*KC0_SPARSE_SIZE
    shell.init_k_KG = k*KG_SPARSE_SIZE
    shell.init_k_M = k*M_SPARSE_SIZE
    elements.append(shell)

Kr = np.zeros(KC0_SPARSE_SIZE*num_elements, dtype=INT)
Kc = np.zeros(KC0_SPARSE_SIZE*num_elements, dtype=INT)
Kv = np.zeros(KC0_SPARSE_SIZE*num_elements, dtype=DOUBLE)
for shell in elements:
    update_KC0(shell, points, weights, Kr, Kc, Kv)
KC0 = coo_matrix((Kv, (Kr, Kc)), shape=(N, N)).tocsc()

Mr = np.zeros(M_SPARSE_SIZE*num_elements, dtype=INT)
Mc = np.zeros(M_SPARSE_SIZE*num_elements, dtype=INT)
Mv = np.zeros(M_SPARSE_SIZE*num_elements, dtype=DOUBLE)
for shell in elements:
    update_M(shell, Mr, Mc, Mv)
M = coo_matrix((Mv, (Mr, Mc)), shape=(N, N)).tocsc()

Boundary conditions#

Both ends are simply supported: \(u\), \(v\) and \(w\) are constrained at the nodes of \(x = 0\) and \(x = L\). Between two nodes of an end, \(w\) is the cubic of the nodal \(w\) and \(w_{,y}\), so with \(w_{,y}\) free \(w = 0\) holds exactly only at the nodes; the deviation between them is small and vanishes with mesh refinement, see Assembling a model.

bk = np.zeros(N, dtype=bool)
ends = isclose(x, 0) | isclose(x, L)
for dof in (0, 3, 6):  # u, v, w
    bk[dof::DOF] = ends
bu = ~bk

Kuu = KC0[bu][:, bu]
Muu = M[bu][:, bu]

Comparison#

The reference is the regression value stored in tests/test_natural_frequency.py, the lowest angular frequency of the same model. The Donnell-type kinematics lose accuracy for modes with few circumferential waves [Leissa1973]; for those modes the Sanders-type element, bfsccylinder.sanders, is the safer choice, see Kinematics of the cylindrical shell.
